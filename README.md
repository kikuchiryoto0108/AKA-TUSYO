マーベラスゲームジャムで、友達と計3人で3日間で開発したゲームです。
プログラムをメインで行い、全員で企画をしました。
PCの場合はマウス左クリックで物を動かしたり、カメラを選択したり。右クリックで写真を撮れます。
スマホの場合は一本タッチで左クリック。二本タッチで右クリックです。
